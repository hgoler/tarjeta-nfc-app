# Tarjeta NFC — app Android

Descarga la última versión: **[tarjeta-nfc.apk](https://github.com/hgoler/tarjeta-nfc-app/releases/latest/download/tarjeta-nfc.apk)**

Comparte tu tarjeta de contacto acercando tu celular Android a otro. Crea tu tarjeta en
https://tarjeta-nfc-hgoler.web.app y luego, desde el editor, toca "Compartir desde mi Android".

Requisitos: Android 8 o superior con NFC. Al instalar, el celular pedirá permitir apps de origen desconocido.
